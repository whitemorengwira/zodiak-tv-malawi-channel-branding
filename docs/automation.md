# Automation & AI Integration — ZODIAK TV

## 1. Infrastructure Automation
Using Terraform, the complete cloud environment for this production can be provisioned in under 90 seconds.

## 2. Automated Pipeline Triggers
* **Instant Proxy Ingestion**: Editors can start cutting within minutes of raw cards finishing their upload.
* **Automated Naming Verification**: Incoming camera files are validated against production naming conventions.

## 3. AI Capabilities
* **Speech-to-Text Transcription**: Audio dialogue is parsed and converted into timecoded SRT subtitle tracks.
* **Automated Technical QC**: Automated video scopes check for illegal RGB gamut levels and audio clipping before manual sign-off.
